# Graphic design styles

A style is a set of constraints, not a filter. Applying one means accepting what it
refuses, not adding its surface to something already designed.

Use this in phase 3 of `creative-studio`, after research and before any building.

## Picking

Three questions decide it:

1. **What does the audience need to feel?** Confidence, delight, nostalgia, urgency,
   calm. One word.
2. **What does the category already look like?** The style has to differentiate, so
   rule out the category default first.
3. **What can this survive?** A style has to hold up across every deliverable. A
   maximalist identity that collapses at favicon size is not finished.

Then read `references/styles.md` for the twenty, and name the direction in the shape
`creative-studio/references/creative-direction.md` sets out.

## Naming a style is not enough

Four projects built in sequence each named a different style and converged on the same
execution anyway: warm off-white ground at L 0.98+, oversized near-black grotesque
headline with a full stop, hairline rule, two-column intro, mono labels top right. Two
shared both typefaces exactly.

The stated style differed every time. The toolkit did not.

So a style is only chosen once it **forfeits specific elements** of whatever the default
toolkit is. Write the forfeits down as a table before building:

| Given up | Replaced with |
| --- | --- |
| The default ground | ... |
| The default headline face | ... |
| The default structural device | ... |

At least two forfeits, named concretely. "Minimalism with warmth" is a label.
"Off-white ground becomes tinted putty, grotesque becomes rounded, hairlines become
soft forms" is a decision that can be checked against the output.

## Rules

- **One style, committed to.** Two styles is no style. The one exception is a deliberate
  base plus one accent move, and the accent has to be nameable.
- **A style is not a mood board.** If you cannot state what it refuses, you have picked
  a look, not a style.
- **Legibility outranks style.** Every one of these can be executed accessibly. If the
  contrast fails, the execution is wrong, not the constraint.
- **Period styles need period accuracy.** Retro, Y2K, Victorian and pop art read as
  costume when the details are approximate. Get the specific decade, the specific
  printing process, the specific software artefacts.
- **Motion follows the style.** Swiss moves precisely and briefly. Clay moves with
  weight. Y2K stutters. A default fade over any of them undoes the choice.

## The twenty

| Style | One line | Best for |
| --- | --- | --- |
| Minimalism | what remains after removal | product UI, premium retail, deep tech |
| Maximalism | abundance as the message | culture, fashion, editorial, events |
| Futuristic | a specific future, not "the future" | deep tech, AI infra, mobility |
| Vector art | flat shape and hard edge | explainers, brand illustration, icons |
| Collage art | fragments in tension | culture, music, zines, campaigns |
| Retro | one decade, done exactly | food and drink, hospitality, nostalgia brands |
| Cyberpunk | high tech, low life | games, security, crypto, nightlife |
| Pop art | mass production as subject | consumer goods, merch, youth brands |
| Glassmorphism | depth through translucency | OS-adjacent UI, dashboards, overlays |
| Clay style | soft mass, friendly physics | onboarding, kids, fintech that wants warmth |
| Pixel art | resolution as a constraint | games, developer tools, retro computing |
| Editorial | type-led, print discipline | magazines, long-form, considered brands |
| Y2K | optimistic early-digital | fashion, music, consumer app launches |
| Swiss | grid, Helvetica, objectivity | institutions, finance, technical, wayfinding |
| Surreal | impossible made plausible | campaigns, culture, luxury, AI products |
| Bohemian | handmade, earthy, imperfect | wellness, craft, hospitality, slow goods |
| Victorian | ornament and density | spirits, apothecary, heritage, publishing |
| Graffiti | mark-making, territory | streetwear, sport, music, youth |
| Aurora | soft luminous gradient | SaaS, AI, anything wanting calm modernity |
| Handwritten | the human hand | personal brands, greetings, food, craft |

Full detail per style, including what breaks it: `references/styles.md`.

## For the portfolio projects

| Project | Style | Why |
| --- | --- | --- |
| AstraForge | Swiss, with editorial | engineering buyers trust the grid and the data table. Futuristic is the category default and would make it look like every other deep-tech site. |
| Fixly | Minimalism, warmth from clay accents only | trust product. Nothing may compete with price clarity and provider credibility. |
| NexaGrid | Swiss, with a considered diagram language | observability means drawing systems. The diagram style is the brand. |
| TraceAI | Minimalism with editorial data display | dense software. Aurora is the SaaS default and would bury the numbers. |
| Flowstate | Minimalism with clay physics in motion | calm surface, weighted motion. The physics carries the personality, not the colour. |
| NOMA | Editorial, with Swiss restraint | premium consumer. Bohemian is the wellness default and is exactly what to refuse. |
| Orbit | Futuristic, disciplined by Swiss typography | it is a film, so it can be more; the type has to stay readable at speed. |

Note the pattern: four of the seven refuse the category default, and that refusal is the
argument each case study makes.

## Avoid as a default

Aurora, glassmorphism and generic futuristic are where AI-generated design lands when
nobody chose. If one of those is right for a project, say why in writing. If it was not
chosen, it is a symptom.
